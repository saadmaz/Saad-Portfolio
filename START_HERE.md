## ⚡ 30-Second Examples

### Add a Project
```json
// Open: src/data/content/projects.json
// Add this object to the array:
{
  "id": 6,
  "title": "My New Project",
  "description": "What it does",
  "date": "2025-12",
  "image": "/assets/projects/image.jpg",
  "technologies": ["React", "TypeScript"],
  "link": "https://project.com",
  "github": "https://github.com/user/project",
  "featured": true
}
// Save - Done! ✅
```

### Add a Job
```json
// Open: src/data/personal/workExperience.json
{
  "id": 4,
  "company": "Company Name",
  "position": "Your Title",
  "startDate": "2026-01",
  "endDate": "Present",
  "location": "City",
  "description": "What you do",
  "technologies": ["React", "Node.js"],
  "achievements": ["Achievement 1", "Achievement 2"]
}
// Save - Done! ✅
```

### Add a Skill
```json
// Open: src/data/personal/skills.json
// Find your category and add this skill:
{ "name": "New Skill", "level": 5, "years": 3, "endorsed": 20 }
// Save - Done! ✅
```
